## 🛠️ Tecnologias e Recursos

- **HTML5** (Estruturação semântica)
- **CSS3** (Estilização avançada e Flexbox/Grid)
- **JavaScript** (Interatividade e animações)
- **Google Fonts** (Tipografia moderna)
- **Design Responsivo** (Adaptável para mobile, tablet e desktop)

---

## 🚀 Funcionalidades

* 🎯 **Navegação Suave:** Scroll suave ao clicar nos itens do menu.
* 📱 **Totalmente Responsivo:** Experiência otimizada para qualquer tamanho de tela.
* 💼 **Apresentação Profissional:** Seções dedicadas à trajetória acadêmica e profissional.
* 📦 **Showcase de Projetos:** Cards interativos exibindo repositórios do GitHub.
* ⚡ **Performance:** Carregamento rápido utilizando apenas código nativo (sem frameworks pesados).

---

## 🗂️ Seções do Site

*   **Hero:** Boas-vindas impactantes com nome, título profissional e call-to-action (CTA).
*   **Sobre:** Resumo da minha trajetória, foco atual nos estudos e objetivos de carreira.
*   **Skills:** Grid visual destacando as tecnologias back-end e ferramentas dominadas.
*   **Projetos:** Galeria com os principais projetos desenvolvidos, contendo descrição e link direto para o código.
*   **Contato:** Links diretos e centralizados para conexões profissionais.

---

## 🎯 Objetivo do Projeto

Este hub foi desenvolvido para centralizar meus principais projetos e tecnologias. O objetivo principal é servir como cartão de visitas profissional para oportunidades de **estágio, vagas júnior e networking** na área de desenvolvimento Back-end.
